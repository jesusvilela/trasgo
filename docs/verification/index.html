04 · evidence boundary

A successful run supports an operational transport claim for the tested prompts, models, providers and date. It does not prove cognitive equivalence, universal losslessness, model-independent reasoning, or that Trasgo is the model's native internal language.

Raw calls and usage are published alongside aggregate JSON. Secrets are never written to artifacts.
