05 / boundary

Evidence boundary

A successful run supports an operational transport claim for the tested prompts, models, providers and date. It does not prove cognitive equivalence, universal losslessness, model-independent reasoning, or that Trasgo is a model's native internal language.

Raw calls, hashes and usage should remain inspectable alongside aggregates. Missing measurements are part of the scientific result.
