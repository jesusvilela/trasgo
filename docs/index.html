Live Sandbox

Try the trasgo CLI right in your browser. The web runtime uses Hugging Face Router with a selectable model backend. Run trasgo models and trasgo model <id> before the live demo.

trasgo — semantic-runtime-shell
Trasgo v0.2.17-verified (Web Sandbox)
Type trasgo --help to see commands, or try the demo loop:
1. trasgo init "demo"
2. trasgo models
3. trasgo model Qwen/Qwen2.5-7B-Instruct
4. trasgo boot
5. trasgo eval
6. trasgo send "Reduce (λx.λy.x) y"
 
$
